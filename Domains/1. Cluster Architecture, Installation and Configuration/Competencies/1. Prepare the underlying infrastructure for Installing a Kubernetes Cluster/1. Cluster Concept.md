# Cluster concept

A cluster is a group of nodes, or machines, that work together. This is true for a database cluster, or
any other type of cluster. A Kubernetes cluster is no different.

In Kubernetes, atleast two Linux nodes work together to form a Kubernetes cluster.


> [!NOTE]
> The exam environment uses Ubuntu, a Debian-based Linux distribution, for Linux nodes. To keep learning consistent with the exam format, we will also use Ubuntu.
